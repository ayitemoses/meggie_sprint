# Résumé - Mission 1 : Le Shell

## 1. Objectifs de la mission
Apprendre les bases du Shell de Linux, pratiquer les commandes directement dans sa VM et resoudre les premiers niveaux du jeu Bandit sur OverTheWire( Level 0 to Level 6)


## 2. Contenu de la mission
Retrouvez le contenu détaillé de la mission dans [voir le dossier mission-1-shell](../mission-1-shell/documentation/mission01.md)

## 3. Résumé final: notions principales

Shell       → interprète les commandes
Bash        → exemple de shell majoritaire sur Linux
/home       → fichiers personnels
/etc        → configuration
/var        → données variables et logs
Chemin      → absolu ou relatif
|           → transmet la sortie d'une commande A à l'entrée d'une autre B
